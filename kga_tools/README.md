# KGA Toolbox

QGIS plugin by Khmer GRS Academy (KGA). This folder is the plugin itself — drop
it in your QGIS profile's `python/plugins/` directory, or install
`kga_tools.zip` through Plugins > Install from ZIP.

Install, packaging and development notes live in the repository README:
https://github.com/sophon-pro/KGAToolbox-QGIS
