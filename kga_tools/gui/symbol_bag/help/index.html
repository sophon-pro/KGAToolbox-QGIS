Symbol Bag {{VERSION}}

Collect once – organize easily – apply anytime.

Smart filter

Select a layer in the Layers panel and the bag shows only symbols that fit it – polygon symbols for a polygon layer, line symbols for a line layer, point symbols for a point layer, terrain & raster styles for a raster. Click Show all in the green strip to see everything; selecting another layer turns the filter back on. Switch it off in ⚙ → Smart Filter by Selected Layer.

Apply a symbol

Symbol Bag applies exactly to what you select in the Layers panel – no questions asked:

  • Select a layer → the whole layer gets the symbol. On a categorized / graduated / rule-based layer every class gets the same style (the classes themselves are kept).
  • Select a category (a legend row under the layer, e.g. one class value) → only that category changes. Ctrl-click several categories to change just those.
  • The strip at the top of the bag always tells you the target: → Applies to class “SS_BM_Gross” of SS_BA_Gross.
  • Double-click a card (or press Enter), or drag a card onto a layer or onto a single category row in the Layers panel.
  • Only symbology changes – data, geometry, attributes and labels are never touched. Ctrl+Z in the bag (or ↺ in the footer) restores the previous style.

Add symbols

  • + → Create Symbol: quick colour/size/width/opacity controls, or the full QGIS Symbol Selector for multilayer symbols. Choose Terrain & Raster to build a pseudocolor style from any colour ramp or to edit any raster renderer (hillshade, paletted, multiband…).
  • Add Current Layer Symbol to Bag – also in the right-click menu of any layer.
  • Import from the QGIS Style Manager, the current project, or files: QML (vector and raster), QGIS XML style libraries, style databases (.db), SLD, SVG and .sbag collections. You can also drop files straight onto the panel.
  • Duplicates are detected and skipped automatically. User SVG files are embedded so symbols keep working if the original file moves.

Organize

  • The folder button next to the search box switches collection and creates, renames, exports or deletes collections. Right-click a card → Move to Collection.
  • In Manual order sort, drag cards to reorder them.
  • Click the ☆ on a card for Favorites. Recent shows what you applied last.
  • Search matches name, tags, description, type and collection – words are combined.

The bag

  • Drag the coloured header to move the bag; drag the bottom-right corner to resize.
  • – hides the bag in a round bubble on the map (click it to open, drag it anywhere). Double-clicking the header does the same.
  • Motion: the bag moves with spring physics – it drops in when opened, is tossed along an arc into the bubble (with a ripple) and springs back out, slides shut like a drawer when folded; the category pill glides between buttons, cards cascade in, lift on hover, pulse when applied and the ☆ pops. Choose Snappy, Normal, Relaxed or Off in ⚙ → Motion.
  • ⚙ → Bag Style…: nine colourways, background transparency, fade, key ring / handle, compact mode, columns, icon size and bubble options. ⚙ also has quick menus for Show As, Columns, Icon Size and Sort.

Symbol Colors – recolor symbols in the bag

  • Open it with the palette button in the bag header, the small palette icon on a symbol card, or right-click a card → Recolor…. It grows out of the button you clicked, sits beside the bag, moves with it and closes with it.
  • Choose what to recolor: Whole symbol (keep shades) – every color follows the new hue while keeping its own light/dark relation; All fill / line colors; All outline colors; or one color of one symbol layer (multilayer symbols, marker lines, pattern fills, recolorable SVGs, font markers).
  • Pick on the wheel (outer ring = hue, left arc = saturation, right arc = brightness), from a palette, Recent or Favorites, type HEX / RGB / HSV, set Opacity, or use the eyedropper to pick any pixel on screen.
  • The card previews the change live – nothing is saved until you choose Save as New or Replace (then double-click the card to apply it). Undo, Redo and Reset work on this session's color edits. Size, shape, widths, layers, rotation and offsets are never changed.
  • Raster ramps: click a stop on the ramp strip to edit it, apply any QGIS color ramp preset, or Reverse.
  • Palettes: nine built-in palettes plus your own – create, rename, delete, add/remove colors, import/export .gpl, or Use in QGIS Color Buttons to see the palette in every QGIS color button.
  • Resize the wheel: the target button in the picker header (Small / Medium / Large) or drag its corner.

Layer Colors – recolor layers on the map (standalone)

  • Open it with the Layer Colors toolbar button (color wheel icon), or right-click a layer → Recolor Layer Colors…. It works on its own – the bag does not need to be open.
  • – (or Done) pours it, macOS-Genie style, into its own color-wheel bubble on the bottom edge of the map (click the bubble or the toolbar button to bring it back, drag the bubble anywhere) – just like the bag. A soft sound plays with it. The speaker button in the header turns sound on / off with one click; right-click it for the volume and the style – Whoosh, Bubble, Chime or Magic (you hear each one as you pick it). The same choices are in the bag's ⚙ → Sound Effects.
  • The Layer box at the top shows the layer being recolored – pick any layer there. With nothing selected in the Layers panel it starts on the top visible layer.
  • Choose what to recolor with the boxes under the name: Whole (every color, keeping shades), Fill color (or Line color), Outline, and Layers ▾ for one layer of a multi-layer symbol.
  • It follows your Layers panel selection: select a category row → only that class is recolored; select a layer → choose one class in the Class list (each shows its own symbol) – or All classes to change every class at once.
  • Every change shows live on the map. Done keeps it and tucks the tool into its bubble (only ✕ closes it); Reset brings back the layer's original colors; Undo / Redo step through your edits; Ctrl+Z in the bag undoes the whole session.
  • Save to Bag stores the recolored symbol (or raster style) as a new card tagged from layer.
  • Raster layers: click a stop on the ramp, apply a color ramp preset or Reverse – live on the map.
  • Thickness wheel (below the swatches): drag around the tapered wheel, type a value or click a preset (0.26 / 0.5 / 1 / 2 mm) to set the line width of a line layer, the outline width of a polygon layer or the marker outline of a point layer – live on the map, for the selected class or all classes. Lines made of several strokes (a casing with a centre line) keep their proportions.
  • The swatch strip shows one set of colors at a time – click its name to switch between your palettes, Recent colors and Favorites; ⋮ holds the palette actions.
  • Only colors and thickness change – sizes, shapes, classes, labels and data stay as they were.

Raster & terrain styles

Raster styles are stored separately from vector symbols. Styles marked "Stretch to each target layer's min/max" (DEM ramps, grayscale, multiband) adapt their value range to the layer you apply them to; class-based styles (slope, aspect, NDVI) keep their absolute values. If a style uses a band that does not exist on the target layer, band 1 is used and you are warned.

Your library

Stored in {{LIBRARY}}. An automatic backup is made each session (configurable in Settings). Use ⋮ → Backup / Restore Library to save or move your whole library, and Export Collection to share a set of symbols (.sbag) with colleagues or students.

Symbol Bag uses only QGIS's own symbol and style classes, so every symbol can be edited with the standard QGIS tools.
