Layer Path Manager — Help

This tool reconnects layers to their data when files have moved, and keeps project paths tidy. It never moves, changes or deletes your original files. It only changes where layers point to (and, with Copy / Move To..., copies or moves data into a folder), always after you confirm.

Fix a project whose data moved

  1. The banner at the top says how many layers can't find their data.
  2. Click Find Missing Data... and choose the folder where the data is now. Sub-folders are searched too.
  3. Check the matches: the old folder is in red, the new folder in green. Rows that need a decision are left unticked. Double-click one to pick the right file.
  4. Click Apply, then Save Project.

Where is my data?

The Folders panel lists every folder that holds layer data, with the number of layers, how many are OK or broken, and the size. Click a folder to list its layers. Double-click it to tick them. Right-click it to copy or move them.

Put layers in one folder

  1. Select the layers: tick them, select rows, or right-click a folder. Select nothing for all layers.
  2. Click Copy / Move To... and choose the new folder.
  3. Choose Copy (originals stay) or Move (originals deleted after checking), then click the button. Done.

Nothing is overwritten. A different file with the same name is saved as e.g. rivers_2.shp. A move can't be undone; a copy can.

Which button?

  • Find Missing Data... — layers lost their files (shown only then): pick the folder where the data is now.
  • Replace File... — one layer should use a different file.
  • Copy / Move To... — put the selected layers' data into a folder.

Change one layer's file

Double-click the layer, or select it and click Replace File. With several layers selected, use Change › Use one file for all selected rows, for example for several layers of the same GeoPackage. Each keeps its own layer name.

Where are the other functions?

  • Problems shows only layers with a problem. Filters adds status, type and provider filters and lets you show more columns.
  • More: check that sources open, relative/absolute paths, health report, prepare for moving, export change log, selection helpers and settings.
  • Undo appears after a change and puts layers back as they were (until QGIS closes).
  • Details (bottom left) shows activity messages, the change log and a summary.
  • For match options (search sub-folders, ignore case, similar names, same sub-folders), open Options in the folder dialog.

Status values

  • Valid / Repaired — the data opens.
  • Broken — the reason is in the Problem column (file missing, unreadable, layer missing inside a GeoPackage, database can't connect).
  • Remote — web services (WMS, XYZ, WFS...).
  • Unsupported — memory and virtual layers without a file.

Safety

Every new file is test-opened read-only before use. Styles, labels, joins and layer IDs are kept. If a layer doesn't open after a change, the old path is restored automatically. Database and web layers are never changed by this tool; fix them in Layer Properties › Source.
