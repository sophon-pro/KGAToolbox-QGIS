about=KGA Toolbox brings a set of practical processing algorithms together under one provider with a dedicated toolbar, adding workflows that QGIS lacks or that otherwise take several steps. Key capabilities:
    - File Geodatabase <-> GeoPackage conversion that carries field domains and layer aliases in both directions
    - GeoPackage Domain Editor for creating and managing field domains inside QGIS
    - Append with Field Mapping for controlled transfer between layers
    - Excel Attribute Round-Trip to edit attributes in Excel and bring the values back safely
    - KGA Layer Package, a self-contained format that keeps layers, styles and settings together for sharing
    - Raster Format Converter for large orthophotos, with resumable conversion
    - Topology checks with an Error Inspector for reviewing data quality issues
    - Interactive editing tools modelled on the ArcGIS Pro Modify Features pane
    - Layout grids and graticules, including MGRS
    - Administrative boundaries, basemaps, elevation models (DEM) and land cover from open data sources
    - Imagery Downloader that stitches web-map tiles into one georeferenced image
    Network use and privacy:
    Only the Add Open Data & Basemaps and Imagery Downloader tools make outbound requests, and only when the user asks for data. Add Open Data connects to geoBoundaries, the Humanitarian Data Exchange (HDX), Natural Earth (served from GitHub), OpenStreetMap, Google and Esri tile services, the Copernicus DEM and ESA WorldCover open-data buckets on Amazon S3, Esri's Living Atlas land-cover image service, OpenTopography, and any service URL the user enters. The Imagery Downloader connects to the chosen imagery tile service only. OpenTopography is the one source that needs an account: the user enters their own free API key, it is kept in the QGIS authentication database and sent only to OpenTopography. Every other source works without an account or key. The only information sent is what a request needs: a country code, the bounding box of the area asked for, or tile numbers. No project data or layers are uploaded, and nothing runs in the background. Downloads are cached in the QGIS profile directory, and rasters and imagery tiles are written only to the folder the user chooses. No other KGA Toolbox tool uses the network.

    - Downloads are cached and use the QGIS proxy settings
    - Add Imagery Downloader: download web-map imagery tiles for an area, stitch them into one georeferenced GeoTIFF/JPEG/PNG/JPEG 2000 in the project CRS, with resume after interruption
    - Add Grid to Layout tool with presets, auto interval, degree graticules and editing of existing grids
    - Add MGRS grids to print layouts, including 100 km square labels and Norway/Svalbard zone exceptions
    - Add KGA Mapping group; move DEM Legend Bar into it (algorithm id unchanged)
