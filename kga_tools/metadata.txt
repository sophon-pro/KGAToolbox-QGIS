about=KGA Toolbox is a set of practical QGIS tools for spatial data management, editing and open data. Key features:
    - File Geodatabase <-> GeoPackage conversion with field domains and aliases
    - KGA Editor toolbar (QGIS 3.44+): Edit Session, Create Features, Modify Features (30 tools), Open Feature Attribute
    - Catalog panel, workspaces and shareable project packages (QGIS 3.36+)
    - Browser Copy and Paste, Domain Editor, Append with Field Mapping, Excel attribute round-trip
    - Layer packages, topology checks and an Error Inspector
    - Open data: boundaries (including a Cambodia database), basemaps, DEM, land cover, web imagery
    - Irrigation tools: contours, rivers and streams, reservoir storage, DEM correction
    - Layout grids, MGRS, guides and Khmer north arrows; callout labels and a symbol gallery
    - Pro-style start page, selection and Layers panel, optional map tabs (Settings)
    - Data Explorer: browse, search, preview and ingest geodata (QGIS 3.44+)
    Not affiliated with or endorsed by Esri. ArcGIS is a trademark of Esri.
    Network use (only when you ask; nothing runs in the background):
    - Add Open Data: geoBoundaries, HDX, Natural Earth (GitHub), OpenStreetMap, Google and Esri tiles, Copernicus DEM and ESA WorldCover on Amazon S3, Esri Living Atlas, OpenTopography (needs your own free API key), and any address you enter. The KGA Database (Cambodia) source reads api.github.com with an access key you enter once, kept in the QGIS password store and sent only there.
    - Imagery Downloader: the chosen tile service. Generate Contour and River tools: the Copernicus DEM bucket, plus Overpass (overpass-api.de, overpass.kumi.systems) only if you tick the OpenStreetMap check.
    - Check for Update: api.github.com, no project data sent.
    - Only a country code, bounding box or tile numbers are sent; no project data or layers are uploaded. Downloads are cached in the QGIS profile.

changelog=
    1.0.0
    - First stable release
    - New: KGA Editor toolbar with Modify Features, Catalog panel, workspaces, project packages (Share Workspace / Import Project Package), Convert Project to Workspace
    - New: Data Explorer, Callout Label Studio, KGA Layer Symbol, Clip Basemap, Layout Guides and Khmer North Arrows
    - New: Settings window (new projects start in WGS 84 / UTM 48N, zoomed to Cambodia, with a basemap), start page, Pro-style selection and Layers panel, map tabs, Layer Auto-Sort, output defaults to the project database and folder
    - New: KGA Database (Cambodia) source in Add Open Data
    - New: Browser Copy and Paste, Duplicate to New Layer, Quick Template, Check for Update
    - New: Generate Contour for ROI, Generate River or Stream for ROI, Reservoir Storage Analyzer
    - Improved: CSV to DEM/Contour (choose X, Y, Z fields), DEM Legend Bar, DEM Elevation Correction, help pages
    - Removed: Storage Capacity Curve (use Reservoir Storage Analyzer) and DEM and Contour Tool (use CSV to DEM and Contour, or QGIS's Contour tool). Models or scripts calling kga:storage_capacity_curve or kga:demcontourtool need updating
    0.2.0
    - Add Raster Format Converter (ECW, GeoTIFF, JPEG 2000, IMG, PNG, JPEG) with resumable block-by-block conversion for large orthophotos
    - Check for an ECW licence key before conversion starts
    - Add Open Data & Basemaps tool: admin boundaries from geoBoundaries, HDX and Natural Earth, GeoJSON/ArcGIS REST/WFS URLs, and XYZ basemaps
    - Open elevation (DEM): Copernicus GLO-30/GLO-90 from AWS with no account, and the OpenTopography catalogue with a free API key; choose the area from the map extent, a drawn shape or a layer, optionally clipped and reprojected
    - Open land cover: Esri 10 m annual (2017 onward) and ESA WorldCover 10 m (2020, 2021), written as a classified GeoTIFF with class names, colours and an attribute table, plus optional polygons
    - Downloads are cached and use the QGIS proxy settings
    - Add Imagery Downloader: download web-map imagery tiles for an area, stitch them into one georeferenced GeoTIFF/JPEG/PNG/JPEG 2000 in the project CRS, with resume after interruption
    - Add Grid to Layout tool with presets, auto interval, degree graticules and editing of existing grids
    - Add MGRS grids to print layouts, including 100 km square labels and Norway/Svalbard zone exceptions
    - Add KGA Mapping group; move DEM Legend Bar into it (algorithm id unchanged)
    - Duplicate Checker: flags now work on Shapefile layers (the field is named dup_status)
    - Layer packages carry picture markers embedded in the style
    0.1.0
    - First public release under the KGA Toolbox provider
    - File Geodatabase <-> GeoPackage conversion preserving domains, aliases, Z/M and curves
    - Shapefile/GeoPackage converters, KML export and layer packages
    - Domain & Schema Manager, Append with Field Mapping and Excel attribute round-trip
    - Topology checks with Error Inspector, Planarize Lines and Duplicate Checker
    - Interactive editing tools: Copy Parallel, Buffer, COGO Lines, Merge, Divide, Clip, Construct Polygon, Sequential Numbering and Copy-Paste Feature
    - Irrigation tools: DEM & contours, hypsometric map, rating and storage curves, DEM correction
    - Bundled help page for every algorithm
